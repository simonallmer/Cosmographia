# LEX-0019: METAPHOR

**Domain:** Aesthetica (The Expressive Domain)
**Genus:** Linguistic Symbolic Device

## Definition
A figure of speech in which a word or phrase is applied to an object or action to which it is not literally applicable, creating a symbolic connection. In the lexicon, Metaphor is the mechanism by which the Psyche maps unknown concepts onto known Materia.

## Logical Constraints
- **Non-Literality:** Is it literally false? Yes (If no → Description)
- **Mapping:** Does it transfer meaning? Yes (If no → Nonsense)
- **Illumination:** Does it provide new insight? Yes (If no → Cliché)

## Essential Components
- **Tenor:** The object or concept being described.
- **Vehicle:** The image or concept used to describe it.
- **Ground:** The shared quality between tenor and vehicle.

## Architecture of Difference
- **vs. Simile:** Simile uses "like" or "as" (comparison); Metaphor asserts identity (substitution).
- **vs. Symbol:** A metaphor is a dynamic action; a symbol is a static representation.

## Examples
- "Time is a thief."
- "The curtain of night."
- "A sea of troubles."

## Cosmograph Suggestion
**Visual Structure:** Two distinct shapes (a circle and a triangle) connected by a dashed bridge. Above the bridge, a third shape (a star) formed by the overlap of the two properties.
