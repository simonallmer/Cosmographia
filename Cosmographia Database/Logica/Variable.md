# LEX-0032: VARIABLE

**Domain:** Logica (The Formal Domain)
**Genus:** Symbolic Placeholder
**Subordinate to:** [Function](lex-0033-function)

## Definition
A symbol, typically a letter, that represents an unknown or changing quantity in a mathematical expression or process. It is the "open gate" of logic.

## Logical Constraints
- **Permutability:** Can its value change? Yes (If no → Constant)
- **Scope:** Is it defined within a system? Yes
- **Identity:** Does it hold a place for a value? Yes

## Essential Components
- **The Label:** The identifier (e.g., $x$, $y$, $z$).
- **The Domain:** The set of all possible values the variable can take.
- **The Assignment:** The act of giving the variable a specific value.

## Architecture of Difference
- **vs. Constant:** A constant is a fixed point ($\pi$); a variable is a moving point.
- **vs. Unknown:** An unknown is to be solved; a variable is to be manipulated.

## Examples
- $x$ in the equation $2x + 1 = 5$.
- A "Variable" in a block of computer code.
- "The weather" (as a variable in an travel plan).

## Cosmograph Suggestion
**Visual Structure:** A perfect square with an opening in the top. An arrow points downward into the square, representing an incoming value.
