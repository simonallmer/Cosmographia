# LEX-0033: FUNCTION

**Domain:** Logica (The Formal Domain)
**Genus:** Transformation Rule
**Higher order of:** [Variable](lex-0032-variable)

## Definition
A relation from a set of inputs to a set of possible outputs where each input is related to exactly one output. It is the "machine" that processes variables.

## Logical Constraints
- **Uniqueness:** Does one input lead to one output? Yes (If no → Relation)
- **Determinism:** Is the rule consistent? Yes
- **Mapping:** Does it connect two sets? Yes

## Essential Components
- **Input (Domain):** What can enter the function.
- **Rule (Mapping):** The logic that transforms the input.
- **Output (Range):** The result of the transformation.

## Architecture of Difference
- **vs. Algorithm:** An algorithm is the steps; a function is the abstract rule.
- **vs. Formula:** A formula is an expression; a function is a relationship.

## Examples
- $f(x) = x^2$ (A simple squaring function).
- A vending machine (Input = Coin/Button, Output = Item).
- "The Law" (Input = Action, Output = Legal Consequence).

## Cosmograph Suggestion
**Visual Structure:** A solid rectangle (the machine) with a dot entering from the left and a circle exiting from the right. A small mechanical gear icon sits inside the rectangle.
