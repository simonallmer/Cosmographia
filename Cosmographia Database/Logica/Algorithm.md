# LEX-0016: ALGORITHM

**Domain:** Logica (The Foundational Domain)
**Genus:** Computational Procedure

## Definition
A finite sequence of well-defined, computer-implementable instructions, typically to solve a class of specific problems or to perform a computation. It is the bridge between raw logic and automated execution.

## Logical Constraints
- **Finiteness:** Does it end? Yes (If no → Infinite Process)
- **Definiteness:** Are steps clear? Yes (If no → Heuristic / Ambiguity)
- **Input/Output:** Does it transform data? Yes (If no → Static Statement)

## Essential Components
- **Instructions:** The discrete steps of the process.
- **Logic Gates:** The decision points (IF/THEN/ELSE).
- **Complexity:** The measure of resources (time/space) required for execution.

## Architecture of Difference
- **vs. Code:** Code is the language; Algorithm is the logic the code implements.
- **vs. Formula:** A formula is a single expression; an algorithm is a sequence of expressions.

## Examples
- A cake recipe (Analog Algorithm).
- PageRank (Search ranking algorithm).
- Bubble Sort (Sorting algorithm).

## Cosmograph Suggestion
**Visual Structure:** A flow chart consisting of three diamonds (decisions) connected by straight lines. Each diamond has two paths leading out. The structure begins at a single point and ends at a single resolved point.
