# LEX-0013: RECURSION

**Domain:** Logica (The Foundational Domain)
**Genus:** Logical Process

## Definition
The process of defining a function or concept in terms of itself, creating a potentially infinite self-referential structure. It requires a "base case" to avoid infinite loops and a "recursive step" to progress toward that base.

## Logical Constraints
- **Self-Reference:** Does it refer to itself? Yes (If no → Iteration / Sequence)
- **Termination:** Is there a base case? Yes (If no → Infinite Regress)
- **Reduction:** Does it move toward the base? Yes (If no → Divergence)

## Essential Components
- **Base Case:** The condition that stops the recursion.
- **Recursive Step:** The part where the function calls itself with a modified input.
- **Stack:** The hierarchical memory of previous states.

## Architecture of Difference
- **vs. Iteration:** Iteration repeats a process; Recursion defines a process by itself.
- **vs. Fractal:** A fractal is a visual representation of recursion in geometry.

## Examples
- The Fibonacci Sequence.
- A mirror reflecting a mirror (Visual Recursion).
- "To understand recursion, you must first understand recursion." (Linguistic Recursion).

## Cosmograph Suggestion
**Visual Structure:** A large square containing a smaller version of itself, which contains a smaller version, and so on. A spiral vector connects the corners of each square, converging toward a central point (the base case).
