# LEX-0055: EMOJI

**Domain:** Technica (The Artificial Domain)
**Genus:** Graphical Symbolic Unit

## Definition
A small digital image or icon used to express an idea or emotion. Unlike emoticons, emojis are standardized Unicode characters rendered as full-color graphics.

## Logical Constraints
- **Substrate:** Graphical? Yes
- **Standardization:** Unicode? Yes
- **Atomic:** Single Character? Yes

## Essential Components
- **Pixel/Vector Data:** The graphical representation.
- **Unicode Code Point:** The standardized numeric ID.
- **Semantic Intent:** The specific emotion or object represented.

## Architecture of Difference
- **vs. Emoticon:** Emojis are graphics; Emoticons use type.
- **vs. Icon:** Icons are often system-specific; Emojis are globally standardized.

## Examples
- 😂 (Face with Tears of Joy)
- ❤️ (Red Heart)
- 🚀 (Rocket)

## Cosmograph Suggestion
**Visual Structure:** A solid boundary (circle) containing graphical features, representing a dedicated object.
