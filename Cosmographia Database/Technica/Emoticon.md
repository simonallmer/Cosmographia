# LEX-0054: EMOTICON

**Domain:** Technica (The Artificial Domain)
**Genus:** Typographic Symbolic Sequence
**Parent of:** [Kaomoji](lex-0056-kaomoji)

## Definition
A pictorial representation of a facial expression using punctuation marks, numbers, and letters, usually written in a sideways orientation.

## Logical Constraints
- **Substrate:** Typographic? Yes
- **Orientation:** Sideways? Yes
- **Standardization:** Unicode Glyph? No (Glyphs are separate characters)

## Essential Components
- **Typography:** The use of standard keyboard characters.
- **Sequence:** The specific order that creates the visual pattern (e.g., `;` + `P`).
- **Abstract Representation:** The mental mapping from type to emotion.

## Architecture of Difference
- **vs. Emoji:** Emoticons are built from type; Emojis are pre-rendered graphics.
- **vs. Symbol:** Symbols are single units; Emoticons are composite sequences.

## Examples
- `;P`
- `:)`
- `:-(`

## Cosmograph Suggestion
**Visual Structure:** A sequence of discrete typographic shapes (dots and lines) forming a primitive face.
